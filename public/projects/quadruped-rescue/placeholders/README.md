# Quadruped Rescue Placeholder Manifest

此目录只存放页面开发阶段的占位素材。后续文件按来源分开：

- `../source-redacted/`：获准公开并完成脱敏的真实照片、视频帧和界面截图。
- `../generated/`：AI 生成的氛围图或概念插画，页面必须标注 `CONCEPT VISUAL`。
- `../charts/`：从获准数据重绘的 SVG/PNG 图表，不存原始敏感数据。
- `./`：临时占位图；正式发布前替换或移除。
