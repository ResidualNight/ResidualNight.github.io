# 机器狗项目 · 公开脱敏规则

更新：2026-09-16。适用于页面正文、素材、代码示例、文件名、下载项、HTML 元数据和仓库中的规划记录。配合 [页面大纲](page-outline.md) 与 [材料核对](source-review.md) 使用。

用户已确认巡检主线与本人负责硬件搭建，尚未确认其他信息的公开范围。提供 PDF 用于规划与核对，不等于其中人物、单位、数据、图片或未公开技术可以发布。未明确的部分采用通用描述、原创原理示意或省略。

## 1. 身份、组织与业务信息

| 信息 | 默认处理 |
| --- | --- |
| 本人真实姓名、联系方式、头像、学工号、签名、履历联系方式 | 移除；公开身份仅使用 `reflex4` |
| 团队成员、教师、顾问及协作者身份 | 不公开，也不保留“姓氏＋同学”等可回溯别称；不从成员表推断本人职责 |
| 学校、实验室、企业、合作单位、竞赛与赛道 | 泛化为“项目团队”“实验场地”等；移除标志、页眉、水印及背景标牌 |
| 项目原名、独特口号、精确参与日期 | 默认使用通用标题；确认必要性与许可后再决定 |
| 客户、合作协议、采购与供应链、成本、报价、融资及财务预测 | 从个人项目页删除，不改成模糊金额继续展示 |
| 专利、受理文件、应用证明 | 默认不展示扫描件、名称、号码、公章、二维码或数量；数量也需确认，且必须区分申请、受理与授权 |

组织、项目名称、地点照片、年份和成果数量组合后也可能识别团队。不能把每个字段单独处理后就视为整页已完成去识别化。

## 2. 技术与硬件内容

- **可用于通用讲解：** 传感器类别、同步与坐标对齐的作用、各模块功能关系。只讲必要内容，不暗示已实现。
- **确认后按需公开：** 具体型号、软件版本、算法来源、改动范围、实验设置与性能结果。型号不等于设备序列号，但可能关联版本与单位，默认先泛化。
- **默认保留在私有资料中：** 未公开算法细节、完整状态方程与实现、调参规则、接线与触发参数、标定矩阵、配置全集、专用协议、内部代码和未公开电路设计。
- **直接移除：** 口令、令牌、内网地址、远程入口、账号、主机名、Wi-Fi 标识、设备序列号、资产标签、内部仓库地址、本地绝对路径与用户名。
- **场地相关：** 不公开部署坐标、可识别地图轮廓、完整路线、设备点位及敏感空间结构。删除坐标标签或平移原点不等于地图已脱敏。

硬件章节可以解释模块职责与搭建过程，不需要公开完整可复现接线方案。照片仍要检查板卡丝印、资产标签和背景。如果真实地图无法在保持可解释性的同时脱敏，改用标明“结构示意”的虚构布局，并移出实验验证区域。

## 3. 事实状态与个人贡献

- 个人职责目前仅确认“硬件搭建”；不自动扩写为电路设计、固件开发、标定、算法或导航开发，也不将商用底盘写为自研整机。
- 材料记载、原始记录可核实、允许公开是三个不同条件，PDF 中出现过不等于可直接上线。
- 硬件已有、采集接入、完成标定、参与融合、通过整机测试分别记录。
- 定位误差、RPE、漂移率、识别精确率、召回率、帧率与同步精度分别核对定义、单位、条件、样本、基线和版本。
- 不把短直线误差写成全场景精度，不把 precision 写成准确率，不把损失收敛写成现场识别能力。
- 本地代码或接口测试不能描述为整机测试通过；零速度指令不能描述为实机制动已达标。
- 试点目标、平台规划和商业预测不能描述为已经达成的成绩。
- 不将不同版本的硬件、算法和实验拼接为一个完整验证案例；前期救援结果不能证明最新巡检系统性能。
- 开源算法与团队改进范围分别归属；团队成果不写为本人独立完成。
- 真实数值不允许公开时删去数据，或另作明确的原理示意，不能用编造的数值冒充“脱敏实测”。

## 4. 图片、视频与隐藏信息

1. 从原件制作独立的发布副本；原始 PDF、全文 OCR、未处理截图、rosbag 和原始点云保留在仓库之外。
2. 检查人脸、证件、工牌、车牌、建筑特征、终端路径、地图、任务名和设备标签。敏感文字优先裁切或不透明遮盖，不依赖仍可辨认的轻度模糊。
3. 位图遮盖必须固化；SVG/HTML 不在隐藏节点、注释或图层中保留原信息；视频检查全部相关帧、音轨、字幕与封面。
4. 清理 EXIF/GPS、作者、标题等元数据，检查文件名、alt、caption、SVG title/desc、SEO 和分享文本中的敏感信息。
5. 确认画面来源、版本关系和公开权限。平台截图不能因出现在报告中就视为团队实际运行界面。
6. AI 画面只可作为明确标注的概念素材，不能进入实验验证、替代运行截图、补绘实验曲线或伪造现场。

公开资源目录只接收完成核对的发布副本。不得先把原图放入 `public/` 再靠 CSS 遮挡、前端裁切或文件名难猜保护。

## 5. 素材交接

每个素材使用脱敏编号登记：拟用章节、内容性质、权利与公开范围确认状态、需要处理的区域、对应版本和最终检查状态。登记表本身不能复制被移除的真实信息。

建议状态：`候选，未公开` → `范围已确认` → `脱敏完成` → `发布副本复核完成`。已有许可持续有效，仅核对是否覆盖当前用途，不重复索取同一许可。

原始报告不作为页面下载附件；仓库文档同样可能公开，不存源文件绝对路径、全文提取或证明文件详情。
