## 已修复问题

### 1. 摄影发布可能留下半套资源（高风险）

- 原因：旧流程先写新 JSON，再删除旧图片目录，最后移动新图片。删除或移动中途失败时，索引可能指向不存在的图片，旧图片也可能已经丢失。
- 修复：图片先在同级临时目录完整生成，索引先写临时文件；发布时把旧图片目录改名为备份，再安装新图片和新索引。索引安装失败会删除未完成的新图片并恢复旧目录；清理备份失败会保留备份并输出明确路径。
- 位置：`scripts/process-photography.mjs` 的 `publishGeneratedAssets`。
- 回归：`tests/process-photography.test.mjs` 覆盖成功发布和索引安装失败后的恢复。

### 2. 摄影脚本可能误删错误路径（高风险）

- 原因：`--output` 原先可指向项目根目录、文件系统根目录，或与输入/索引路径互相包含；后续递归删除会扩大影响范围。
- 修复：发布前拒绝根目录、项目根目录，以及 input/output/data 的危险重叠组合。
- 位置：`scripts/process-photography.mjs` 的 `assertSafePaths`。

### 3. 摄影日期和组 ID 校验不足（中风险）

- 原因：`2026-02-30` 这类不存在的日期可通过格式检查；重复组 ID 会写入同一图片目录并产生冲突记录。
- 修复：加入真实日历校验和跨组 ID 唯一性检查。
- 位置：`scripts/process-photography.mjs` 的 `assertDate` 与主处理循环。
- 回归：日期失败用例确认旧图片和旧索引均保持不变。

### 4. 受限浏览器中博客链接可能失效（中风险）

- 原因：读取 `sessionStorage` 已有容错，但写入和清空没有；隐私模式、存储禁用或配额已满时，点击分类、Tag、文章或返回按钮可能被同步异常中断。
- 修复：写入和清空都改为安全降级；无法持久化时仍允许原生链接跳转，返回使用 `/blog` 兜底。
- 位置：`app/blog/navigation.ts`。

### 5. 定时文章会让静态导出测试误报（中风险）

- 原因：原测试只排除 `draft: true`，没有按 `publishAt` 或文章日期排除尚未发布的 Markdown。
- 修复：测试使用与内容管线一致的发布时间语义，只要求当前已发布文章存在于导出目录。
- 位置：`tests/static-export.test.mjs`。

### 6. 静态导出缺少站内链接/资源完整性检查（防回归）

- 修复：遍历全部导出 HTML，校验根相对 `href` 和 `src` 最终都能解析到 `out/` 内的页面或资源。
- 位置：`tests/static-export.test.mjs`。

### 7. 默认测试命令会跳过新增测试文件（防回归）

- 原因：`npm test` 固定只执行 `tests/static-export.test.mjs`，新增的摄影失败恢复测试虽然可单独通过，但默认回归不会运行它。
- 修复：测试命令改为执行 `tests/*.test.mjs`，后续同目录测试会自动纳入。
- 位置：`package.json`。
