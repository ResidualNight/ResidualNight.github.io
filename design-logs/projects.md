## 不可丢失的决策

- QuotaDock 的功能与进展以 2026-10-02、0.2.0 / build 14 资料为基线；不得把历史图写成当前实机截图，或宣称正式发布、公证、Intel 支持及完整多屏/全屏验收。下载入口指向版本说明页。中文关键标题按短语换行，避免窄屏拆词。

- 机器狗页个人职责仅为已确认的“硬件搭建”；不自动归属算法、导航、电路或固件工作。图示不得冒充实物或实测，前期实验不得用于证明当前巡检性能。

- 项目目录中的每个条目必须是有效的原生文档链接，不能恢复为无响应的占位文字。
- 正式项目内容未完成时保留简洁占位页；不虚构功能、进度、发布日期或下载入口。
- 后续扩展详情时沿用档案编号和杂志分栏，不改成通用产品落地页或 SaaS 卡片墙。
- 顶部导航必须始终位于项目正文和其他浮动元素之上。
- RSS 页的内容边界必须保持诚实：只写 RSS 2.0，不宣称实时新闻、无限滚动、Atom、全文抓取、未完成的安全验证或未实测的续航数字。
- `540 × 590` 仅描述设备 UI 的安全可见区，不用作照片比例。实拍首屏与列表以 4:5 呈现，完整保留屏幕和机身；背面按键标识以 3:2 取景。原文件保留，网页资源只转码缩放、去元数据，展示裁切和轻微提亮用 CSS 实现，不重绘屏幕文字。
- 明日方舟项目必须始终明确 Lite/v1 规格、来源动作与 Codex 状态映射的区别、历史验证日期、人工验收门控和非官方版权边界；不得提供游戏素材或成品宠物下载。
