# 博客设计日志

## 页面范围

- 路由：`/blog`、`/blog/[slug]`
- 主要实现：`app/blog/page.tsx`、`app/blog/BlogArchive.tsx`、`app/blog/[slug]/page.tsx`、`app/blog/markdown.ts`、`app/blog/content.ts`、`app/blog/search.ts`
- 共享导航：`app/components/SiteNav.tsx`
- 目的：以复古写作档案的方式浏览、检索和阅读 Markdown 文章。

## 当前状态

- 博客首页已从占位页升级为功能页，使用“写作归档”标题和杂志式记录列表。
- 浮动内部导航提供文章列表、分类索引和搜索三种视图；当前视图使用明确活跃状态。
- 搜索索引在静态构建时从全部公开 Markdown 自动生成，并随博客页面交给浏览器本地检索，不依赖线上 API；继续支持中英文多关键词、引号短语、字段权重、正文片段、安全高亮、命中来源、URL 查询恢复和加载/空结果/错误状态。
- Markdown 发布管线对必填字段、日期、Tag、布尔字段、未知字段和文件名 Slug 做构建期校验；草稿与未到发布时间的文章从全部公开表面统一排除，编号、摘要和阅读时间由正文自动生成。
- 分类卡片、列表分类、列表 Tag、文章分类和文章 Tag 均可点击；筛选条件写入 `category` / `tag` URL 参数，刷新、分享和文章返回后保持一致。
- Markdown 文章页包含分类、日期、阅读时长、摘要、标签、GFM 正文、KaTeX 数学公式和上下篇导航。
- 文章页、分类索引、搜索和分类/Tag 筛选结果左下角提供固定圆形返回按钮；返回使用会话内的显式父层栈并替换当前页面，不依赖浏览器“上一步”，避免父子页面循环。
- 博客顶级导航使用原生文档链接，保证页面进入时从顶部开始。
- 整体沿用米白纸张、油墨黑结构、酒红活跃状态和等宽档案编号。

## 不可丢失的决策

- Markdown 是文章的内容源，文章页必须保留完整排版、GFM 支持、标签和分类语义。
- 博客视觉是“档案 / 编号 / 记录”，不改成通用卡片新闻流或 SaaS 仪表盘。
- 文章列表、分类与搜索是同一档案的三种视图，它们必须共享一致的导航状态和记录样式。
- 搜索索引只能在构建期从公开 Markdown 内容源自动派生，不维护示例文章专用数据或手写索引；新文章必须在无需修改搜索代码和部署 API 的情况下进入索引。
- 公开文章集合必须由同一发布规则产生；列表、搜索、分类、详情和上下篇不得分别实现草稿或定时发布判断。
- 档案编号按实际发布时间从旧到新自动编排；插入更早日期的文章会引起后续编号顺延，这是自动编号的既定行为。
- 文章正文的可读性高于装饰密度，纹理不得遮挡长文阅读。

## 待办与已知边界

- 后续补充真实 Markdown 文章和内容管理入口。
- 文章数量增长后评估分页、标签独立索引和归档年份筛选。
- 不开发 RSS、sitemap 或额外社交分享 SEO 管线；保留现有页面基础 metadata 即可。
- 隐藏后台是待评估能力，在安全和身份验证方案确定前不暴露公开入口。
